# AM Preset Finder - Vercel Edition (4nt)

Aplikasi Web Pemindai & Ekstraktor Preset Alight Motion (5MB & XML) lengkap dengan Vercel Serverless Function backend.

## 🚀 Fitur Utama
- **Backend API Serverless (`/api/find` & `/api/search`)**:
  - Ekstraksi tautan preset `alight.link`, Google Drive XML, & MediaFire secara real-time.
  - Integrasi pencarian video JJ TikTok / YouTube.
- **Tampilan Neo-Brutalism**: Warna kontras tinggi, border tegas, dan animasi responsif.
- **Atribusi Footer**: Menyantumkan `© 2026 4nt. All rights reserved.` dan `Web ini terinspirasi dari ampresetfinder.web.id`.

## 🛠️ Cara Deploy ke Vercel (Gratis & Mudah)

### Opsi A: Menggunakan Vercel CLI
1. Extract file zip ini.
2. Buka terminal di folder project ini.
3. Jalankan command:
   ```bash
   npm install -g vercel
   vercel
   ```
4. Tekan Enter untuk menyetujui opsi default Vercel. Web langsung online!

### Opsi B: Menggunakan GitHub + Vercel Dashboard
1. Upload folder project ini ke repository GitHub baru kamu.
2. Buka [Vercel Dashboard](https://vercel.com/dashboard) -> klik **Add New Project**.
3. Import repository GitHub kamu, lalu klik **Deploy**.

Selesai! Aplikasi web AM Preset Finder 100% aktif dan siap digunakan.
